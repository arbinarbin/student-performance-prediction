\# Student Performance Prediction Using Machine Learning



\## 1. Project Overview

This project uses Machine Learning to predict student academic performance based on different student-related factors.



\## 2. Objective

To develop a classification model that predicts a student's Grade Class using factors such as study time, absences, parental support and extracurricular activities.



\## 3. Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn

\- Jupyter Notebook



\## 4. Machine Learning Algorithm

Random Forest Classifier



\## 5. Project Workflow

1\. Data Collection

2\. Data Exploration

3\. Data Preprocessing

4\. Feature Selection

5\. Train-Test Split

6\. Model Training

7\. Model Evaluation

8\. Prediction



\## 6. Project Structure

\- dataset/ - Dataset stored locally

\- notebooks/ - Jupyter Notebook

\- reports/ - Prediction results

\- src/ - Saved trained model

\- README.md - Project documentation



\## 7. How to Run

1\. Clone this repository.

2\. Install the required Python libraries.

3\. Place the dataset CSV file inside the dataset folder.

4\. Open the notebook folder.

5\. Run student\_performance\_prediction.ipynb.



\## 8. Project Status

Model training and prediction completed.
